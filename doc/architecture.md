# Architecture

The single-module, non-web Spring Boot entry point executes one batch, closes its context and propagates failures as nonzero exit status. `DigestProperties` validates configuration before processing. `FeedSource` retrieves bounded RSS/Atom metadata, filters publication time, deduplicates normalized URLs and verifies candidate links with HEAD; `ClaudeAnalyzer` sends bounded untrusted metadata and a versioned prompt/profile to the Messages API and requests schema-constrained output. Java validates every selected ID, score and required field before writes. Full article bodies are not retrieved.

`MongoDigestStore` creates a unique URL index and a single lock document, persists source metadata, analysis and timestamps, and tracks PENDING, SENDING, SENT, FAILED and AMBIGUOUS delivery states. It returns eligible records in descending score order. `TelegramDelivery` sends plain-text messages, handles 429 `retry_after` with bounded in-process retries and persists the future retry time. Network timeouts, 5xx and malformed responses are ambiguous. No automatic retry occurs for ambiguous or in-flight records. A process crash leaves the lock and requires review. A MongoDB failure after Telegram acceptance cannot be resolved automatically and prevents an exactly-once guarantee.

HTTP response sizes and end-to-end request durations are bounded. Processing an already persisted pending item does not require another model call; if fresh discovery or analysis fails, eligible pending items are still attempted and the batch exits nonzero. The offline fixture replaces external source/model/delivery boundaries but uses the same validation, database and batch flow. Compose provides a health-checked MongoDB and persistent named volume; it does not add a scheduler, API, or restart loop.

The checked-in dependency tree originally contained no Claude client. The actual integration choice, official API references and source coverage tradeoff are in [ADR 0001](adr/0001-source-bound-analysis.md). Live model and Telegram behavior remain unverified without explicit authorization to incur cost or send messages.

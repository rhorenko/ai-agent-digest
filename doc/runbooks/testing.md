# Testing

Run `.\mvnw.cmd verify` (or `./mvnw verify`). Ordinary Java tests use in-memory boundaries, and HTTP tests use loopback stubs. MongoDB integration uses Testcontainers and is skipped if Docker is unavailable. No test makes a paid Claude request or sends Telegram messages. Run focused tests, for example `.\mvnw.cmd "-Dtest=DigestBatchTest,ExternalClientsTest" test`. For offline end-to-end verification, follow the separate database Compose demo in README and inspect `news_items`, the unique index, and the exit code. Requirements and results are in the acceptance matrix and verification report.

# Backlog

Keep this list ordered by product priority. A backlog item is not accepted work until its linked feature and verification evidence say so.

| Priority | Item | Type | Status | Feature | Notes |
|---|---|---|---|---|---|
| _1_ | _Outcome-oriented item_ | Feature / discovery / maintenance | Proposed | _Link when created_ | _Dependencies or questions_ |

## Status vocabulary

- `Proposed` — not yet committed.
- `Ready` — requirements and acceptance criteria are sufficient.
- `In progress` — active implementation or verification.
- `Blocked` — blocker is recorded in `project-state.md`.
- `Done` — accepted with linked evidence.
